账号密码连接

直接连接 Linux 服务器，无需预先配置 SSH 别名或公钥。

端口留空使用 22。首次成功连接会记住主机密钥；密钥变化时拒绝连接。不支持验证码或多因素登录。

连接服务器

可点击“账号密码连接”填写地址、可选端口（默认 22）、用户名和密码。服务器需启用普通 SSH 密码认证。勾选记住密码时，密码由系统安全存储保护；否则只保留到退出应用。首次成功连接会记住主机密钥，变化时拒绝连接。

原有别名方式：本应用读取当前系统的 OpenSSH 配置，使用 SSH Host 别名连接 Linux 服务器。

  1. 安装系统 OpenSSH 客户端。Windows：在“可选功能”中安装 OpenSSH 客户端；Linux：使用发行版软件包管理器安装 openssh-client。
  2. 在 SSH 配置中添加服务器别名：macOS / Linux 为 ~/.ssh/config，Windows 为 %USERPROFILE%\.ssh\config。
  3. 先在终端运行 ssh 你的别名，核对主机指纹，完成公钥或 ssh-agent 免交互认证。此方式不使用密码输入框。
  4. 服务器需要 Linux、Python 3；NVIDIA GPU 指标需要 nvidia-smi。所需 VPN 应保持在线。

新 Mac 版本首次启动会导入旧版服务器与分组。之后两版独立保存。配置位置：macOS 为 ~/Library/Application Support/ServerResourceMonitorDesktop，Windows 为 %APPDATA%\ServerResourceMonitorDesktop，Linux 为 ~/.config/ServerResourceMonitorDesktop（遵循 XDG_CONFIG_HOME）。
