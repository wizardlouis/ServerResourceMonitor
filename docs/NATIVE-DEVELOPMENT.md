# 原生 Apple Silicon 后续开发

## v0.6.1 · 2026-10-29

基于本机正在运行的 SwiftUI v0.6.0 开发，仅针对 Apple Silicon macOS 13+。跨平台 v1.0.1 的代码和发布包保持原版本。

新增顶部齿轮“设置”及 macOS 应用设置入口。CPU 核心编号可选十进制（默认）和十六进制，后者使用大写 A–F，不加 0x，以减少字符。示例：15 → F、16 → 10、255 → FF，合并范围 16–31 → 10–1F。十六进制灯阵标题标注 HEX；悬停和辅助朗读保留十进制实际编号，便于与系统工具核对。

所有服务器共用此显示偏好，立即生效，通过原生应用 UserDefaults 的 coreIDRadix 键保存，重启保留。仅影响核心编号与范围；核心数量、使用率、排序、采集与聚合算法不变。

实现：CoreGrouping.swift 提供进制格式化；Monitor.swift 的 HostCard 读取偏好并传至 CoreGrid/CoreCell；等值更新包含进制，避免切换后显示缓存。构建版本为 0.6.1 / 8，不覆盖 GitHub v1.0.1 标签或发布包。

验证命令：

```sh
swiftc native/CoreGrouping.swift native/tests/main.swift -o /tmp/server-monitor-core-tests
/tmp/server-monitor-core-tests
./native/build.command
codesign --verify --deep --strict 服务器资源监控器.app
```

测试覆盖十六进制 9/A、F/10、FF/100 边界，合并范围、十进制保持、无效进制回退，并保留五档核心聚合检查。

本机验证结果：格式化与聚合检查通过，arm64 构建和严格签名检查通过。实际界面通过齿轮设置选择十六进制，已观察到 A–B、E–F、10–11 等范围及 HEX 标记；退出重启后四台服务器仍使用十六进制且继续在线采集。当前本机保持十六进制显示。本次尚未发布新的 GitHub Release。

## v0.6.2 · 2026-10-31

新增“设置 → 界面显示 → 服务器面板 → 详细 / 简略”。默认详细，保留原布局；所有服务器共用 serverPanelTheme 偏好，选择即时生效并自动保存。

简略模式隐藏服务器副标题、CPU/内存说明、核心灯阵编号和百分比及底部图例、GPU 温度功耗；CPU/内存及 GPU 两项指标改为标签与百分比同一行、同字号，保留灰色标签、白色数值及绿/蓝用量条。灯泡继续支持悬停与辅助朗读，保留核心聚合菜单和趋势图。

GPU 计算进程按用户汇总为用户、GPU 编号、显存合计 MiB 三列。GPU 编号去重排序，连续至少三个使用 ASCII 连字符（0-7），两张或离散编号使用顿号（0、1、3）。显存按该用户的所有 GPU 进程记录求和，任何记录缺失则标记数据不全；未知 GPU 显示未知。详细模式仍显示逐进程列表。

JobSummary.swift 提供纯数据汇总；测试命令更新为：

```sh
swiftc native/CoreGrouping.swift native/JobSummary.swift native/tests/main.swift -o /tmp/server-monitor-core-tests
/tmp/server-monitor-core-tests
```

测试覆盖范围边界、去重、跨 GPU 同 PID 的显存累加、未知用户/GPU、缺失显存和空列表。测试、arm64 构建、严格签名检查及差异空白检查通过；实际界面验证设置入口、简略灯阵、单行指标和用户汇总（包括 0-3 / 4-7），6 台服务器恢复在线。仅本机原生版更新，未提交或发布。

## v0.6.3 · 2026-10-31

GPU 区域新增单卡、2/4/8 卡合并菜单，默认单卡；按 GPU 数字编号排序分块，尾组保留实际卡数。每台服务器分别保存 gpuGrouping.<SSH别名>。组内利用率算术平均，已用显存/容量分别求和后计算占比，详细模式显示最高温度和总功耗；某指标任一成员缺失则该组指标显示未知。标题标明实际 GPU 编号、卡数和总容量，混合型号标注混合型号，悬停显示成员型号与计算口径。进程汇总继续使用实际 GPU 编号。

设置 → 界面显示 → 分组与顺序，新增竖组（默认）/横组。竖组每组一列、成员上下排列；横组每组一行、成员左右排列。groupOrientation 全局自动保存。两种模式共用原配置顺序，左/右键仍是前移/后移一位，在横组映射为上移/下移；边界不移动。排序标牌列表和提示同步方向，切换方向保留面板状态。

验证：全部数据测试、arm64 构建、签名与差异检查通过。实际界面验证 8 张 A100 合并为 #0-7、640.0 GiB，横组双成员并排，左右键移动及边界不动；重启确认横组偏好和 GPU 合并档位保留。6/6 台在线。测试后恢复竖组、单卡和原分组顺序，保持简略主题。无 Git 提交或发布。

当前完整测试命令：

```sh
swiftc native/CoreGrouping.swift native/JobSummary.swift native/GPUGrouping.swift native/tests/main.swift -o /tmp/server-monitor-core-tests
/tmp/server-monitor-core-tests
```
